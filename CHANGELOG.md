# Changelog

## 2.9.6

- Added version-aware handling for renamed potion effects, entity types, attributes, tooltip flags, and particles.
- Added a backward-compatible build targeting Paper 1.18.2 and newer, plus a native Paper 26.3 build.
- Removed the runtime requirement on Lib1711.
- Compiled against Paper API 1.18.2, 1.19.4, 1.20.4, and 26.3. Live testing on older servers remains pending.

## 2.9.5

- Modernized the build for Paper 26.3.
- Replaced Lib1711 calls with an internal compatibility API.
- Added optional plugin integration handling.
